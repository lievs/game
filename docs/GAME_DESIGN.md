# Последний курьер — Game Design

## Цель
Сделать динамичную браузерную игру для Яндекс Игр: доставка + исследование города + развитие курьера + риск/награда + сюжет.

## Core loop
1. Получить заказ.
2. Выбрать маршрут.
3. Доехать с учетом заряда и форсажа.
4. Выполнить доставку быстро и без риска.
5. Получить деньги и репутацию.
6. Улучшить транспорт/снаряжение.
7. Открыть новые районы и сюжетные задания.

## Анти-скука
- разные типы заказов и сроки;
- случайные дорожные события;
- погодные модификаторы;
- новые районы с повышенным риском;
- серии безошибочных доставок;
- развитие транспорта;
- фракции и репутация;
- сюжетные решения и несколько финалов;
- испытания и лидерборд.

## Визуальный стиль
Стилизованный top-down город с неоном, объемным светом, дождем, туманом, отражениями, транспортом и частицами. Графика должна быть выразительной, но оптимизированной для браузера.

## Техническая база
- Phaser 4.2.1
- TypeScript
- Vite
- Yandex Games SDK
- localStorage fallback + облачное сохранение Yandex Player

## Этапы
### Vertical slice
Город, курьер, транспорт, заказ, доставка, экономика, сохранение.

### Production gameplay
Районы, трафик, NPC, события, погода, гараж, апгрейды, карта, сюжет.

### Polish
Звук, музыка, VFX, анимации, UI/UX, обучение, баланс, мобильное управление.

### Release
Реклама, rewarded ads, лидерборд, аналитика, cloud save, оптимизация, QA, модерация Яндекс Игр.
